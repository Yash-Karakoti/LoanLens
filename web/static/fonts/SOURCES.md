# Self-hosted typefaces

These files are distributed under the SIL Open Font License 1.1. The complete upstream license texts are included beside the fonts. The website loads only local assets; no external font request is required at runtime.

| Local file | Official upstream source |
| --- | --- |
| `dm-sans-variable.ttf` | https://raw.githubusercontent.com/google/fonts/main/ofl/dmsans/DMSans%5Bopsz,wght%5D.ttf |
| `DM-Sans-OFL.txt` | https://raw.githubusercontent.com/google/fonts/main/ofl/dmsans/OFL.txt |
| `instrument-serif-regular.ttf` | https://fonts.gstatic.com/s/instrumentserif/v5/jizBRFtNs2ka5fXjeivQ4LroWlx-2zI.ttf |
| `instrument-serif-italic.ttf` | https://fonts.gstatic.com/s/instrumentserif/v5/jizHRFtNs2ka5fXjeivQ4LroWlx-6zATiw.ttf |
| `Instrument-Serif-OFL.txt` | https://raw.githubusercontent.com/google/fonts/main/ofl/instrumentserif/OFL.txt |

The Instrument Serif font URLs were obtained from the official Google Fonts CSS endpoint: https://fonts.googleapis.com/css2?family=Instrument+Serif:ital@0;1&display=swap . DM Sans supplies normal variable weights. Instrument Serif supplies normal and italic display styles. Downloaded for the UI redesign on 2026-11-16. No lender's proprietary font is copied.
