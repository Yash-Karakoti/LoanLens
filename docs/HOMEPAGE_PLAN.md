# Homepage and overall UI revision

The user requested a true homepage with a hero section and a more complete, polished visual experience across the website. The previous dashboard-only root is superseded, while its real screening functions remain intact.

## Scope

- `/` becomes the public introduction: navigation, housing hero, clear assessment CTA, actual model/dataset evidence, how-it-works content, a real interactive example, FAQ and footer.
- `/workspace` retains the operational overview. Assessment, batch, evidence, methodology and references keep their existing routes and model behavior.
- The whole site adopts a coherent forest-green, warm-ivory and sage identity informed by real Better and Blend homepages. Typography, form controls, spacing, charts and navigation are revised together. Measured reference evidence is in `HOMEPAGE_RESEARCH.md`.
- Use self-hosted licensed fonts and an original generated housing visual. That image is an illustration, not an applicant's property; no fabricated customer, savings, loan-rate or approval claims are added.
- Keep native HTML/CSS/JavaScript and the existing Python API. Do not add a framework or plugin merely for decoration.

## Integrity and tests

Preserve the fitted model/raw checksums, both existing threshold policies, validation, CSV safeguards and asynchronous state guards. A pre-existing untracked `recipes.json` belongs to the user and must remain untouched and unstaged.

Update route tests, seven-page responsive checks, home/workspace navigation, anchors, mobile menus, keyboard behavior, real-example loading and accessibility checks. Rebuild and verify the existing container path. Historical Mercury comparison artifacts remain as evidence of the previous revision, not a claim that the new design still uses that palette.
